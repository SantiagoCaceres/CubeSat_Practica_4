# Hojas de datos y documentos de referencia

Los documentos locales se copiaron sin modificaciones. Las nuevas descargas se realizaron el 26 de octubre de 2026. Los archivos originales de comunicaciones permanecen en `Docs/`, sin cambios. Los documentos pertenecen a sus respectivos fabricantes.

## Referencias adicionales

- [Ficha del modelo de cámara XIMEA](https://www.ximea.com/products/hyperspectral-imaging/xispec-hyperspectral-miniature-cameras/imec-sm-range-600-1000-usb3-hyperspectral-camera). El manual xiSpec2 está archivado arriba.
- [Molex 436500200](https://www.molex.com/en-us/products/part-detail/436500200): candidato de conector de potencia; el conector genérico de la captura sigue pendiente de validación. No se presenta como una referencia física ya implementada.
- Los esquemáticos y layout de referencia CC112xEM están en la carpeta superior `Docs/`.
- SN74AXC2T245, ESD321 y TPS25947/48 son referencias evaluadas; comprobar su estado de implementación en el esquemático y en el informe. Las fichas de pasivos originales no sustituyen la comprobación de cada referencia de la BOM final.

`indice.csv` registra la URL de origen, el uso, el número de páginas, el tamaño y SHA-256 de cada PDF. Se comprobó que los PDF pueden abrirse; este archivo no certifica la validación eléctrica del diseño.
