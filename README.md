# PCB Integrada Central y de Comunicaciones - CubeSat UD34

**Integrantes:**
- Daniel Felipe Yépez Taimal
- Santiago Cáceres Vásquez

**Versión de Altium Designer: 26.9.1** 

**Instrucciones para abrir el proyecto:**
1. Clonar este repositorio localmente.
2. Navegar al directorio `Altium_Project/PCB_Project` dentro del repositorio clonado.
3. Abrir `PCB_Project.PrjPcb` directamente desde Altium Designer.
4. El diseño utiliza exclusivamente librerías locales integradas (`.SchLib` y `.PcbLib`) alojadas en el directorio `Librerias`, sin dependencias de servidores en la nube ni de entornos de workspace externos.

**Estado del avance OBC:** consultar [alcance y pendientes de revisión](Docs/Estado_avance_OBC_2026-10-26.md). La publicación del avance no sustituye la validación ERC ni la revisión de modelos en Altium.
